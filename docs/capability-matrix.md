## 1. Capability Status Definitions

To maintain strict engineering honesty and credibility, every capability in ORION is classified into exactly one of five verified states:

* **VERIFIED / WORKING**: Fully implemented in source code and backed by live test execution, automated test suites, or live API evidence.
* **PARTIALLY IMPLEMENTED**: Architectural structure and core methods exist, but end-to-end functionality or external integration is incomplete.
* **EXPERIMENTAL**: Functional in code but unstable, unbenchmarked, or under active iteration.
* **PLANNED**: Architecturally designed or discussed in documentation, but not yet implemented in executable source code.
* **UNKNOWN**: Capability cannot be verified with high confidence without additional hardware, services, or test criteria.
