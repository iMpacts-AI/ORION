## 2. Complete End-to-End Runtime Chain

```mermaid
sequenceDiagram
    autonumber
    actor User as Operator
    participant UI as App.tsx (HUD Command Bar)
    participant Preload as preload.ts (contextBridge)
    participant IPC as index.ts (ipcMain)
    participant Orch as OrionOrchestrator.ts
    participant Router as OrionAIProviderRouter.ts
    participant Adapter as OpenRouterProvider.ts
    participant Cloud as OpenRouter Cloud API
    participant Model as meta-llama/llama-3.3-70b-instruct
    participant ToolDAG as ToolDependencyGraph / ToolService.ts
    participant Synth as ContextBuilder.ts

    User->>UI: Submit natural language query
    UI->>Preload: orionApi.processCommand(query, 'TEXT')
    Preload->>IPC: ipcRenderer.invoke('orchestrator:process_command')
    IPC->>Orch: orchestrator.processCommand(query, 'TEXT')
    Orch->>Router: aiProvider.plan(query, availableTools)
    Router->>Adapter: selectBestProvider('PLANNING')->plan(...)
    Adapter->>Cloud: POST https://openrouter.ai/api/v1/chat/completions (Bearer Key)
    Cloud->>Model: Execute JSON Task Planner Prompt
    Model-->>Cloud: JSON Plan (goal, steps, toolToCall, arguments)
    Cloud-->>Adapter: HTTP 200 OK + JSON Payload
    Adapter-->>Router: Validated AIPlan
    Router-->>Orch: AIPlan
    Orch->>ToolDAG: Construct DAG & Execute Batches
    ToolDAG->>ToolDAG: Execute System/File/Automation Tools
    ToolDAG-->>Orch: ToolResults[]
    Orch->>Synth: buildSynthesisContext(query, history, observations)
    Synth-->>Orch: Bounded Safety-Partitioned Prompt
    Orch->>Router: aiProvider.chat(synthesisPrompt)
    Router->>Adapter: chat(...)
    Adapter->>Cloud: POST https://openrouter.ai/api/v1/chat/completions
    Cloud->>Model: Reason over observations & formulate answer
    Model-->>Cloud: Synthesized Answer
    Cloud-->>Adapter: HTTP 200 OK
    Adapter-->>Router: Final Response String
    Router-->>Orch: Final Response String
    Orch-->>IPC: ProcessCommandResult
    IPC-->>Preload: ProcessCommandResult
    Preload-->>UI: Display in HUD Activity Log
    UI-->>User: Visual & Operational Intelligence Presented
```
